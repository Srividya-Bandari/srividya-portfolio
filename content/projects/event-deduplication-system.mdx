## The Platform

I architected OPENLANE's unified full-stack inspection platform — a C#/.NET backend with a React frontend — with 5+ cross-functional teams. In the last 16 months, the service handled inspections of **$50B+ in inventory**, with **over 500K inspections a month** at **99.9% uptime**.

## Faster Inspection Workflows

- Cut inspection workflow latency **35%** with async Carfax and VIN-decoding consumers on a config-driven C#/.NET engine.
- Built the React flow from VIN photo to report.
- Shipped with zero downtime via LaunchDarkly-flagged parity runs and end-to-end tests.

## Unified Carfax Service

I saved **$1.2M a year (8% of Carfax spend)** by cutting duplicate report requests across acquired marketplaces. I designed, built and launched a unified Carfax service with:

- Idempotent deduplication
- Redis caching
- Async callbacks to avoid vendor timeouts

## Vendor-Agnostic VIN Decoding

In a self-initiated Java Spring Boot to .NET migration, I moved VIN decoding to one vendor-agnostic API for all OPENLANE B2B and B2C clients, and communicated the design in design and code reviews.

- My design's caching and check-digit filters stop bad VINs before a paid vendor call, cutting VIN-decoding costs **~20%**.
- A hybrid vendor waterfall raised VIN-decode success from **92% to 98%**.

## Observability and Rollouts

I owned observability for .NET services on Azure:

- Built Honeycomb metrics, dashboards and alerts
- Wrote the on-call runbooks for incidents
- Led canary rollouts (1% → 10% → 50% → 100%) with automatic rollback on Terraform-based Azure infrastructure
