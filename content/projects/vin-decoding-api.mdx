## Overview

A full-stack retrieval-augmented generation (RAG) app: upload a PDF, ask questions, and get answers grounded only in that document, with page citations.

I cut irrelevant answers **40%** on a 100-question eval set by building the retrieval-augmented generation pipeline — hybrid FAISS vector search, reranking, and the OpenAI API.

## How It Works

1. **Upload.** The user uploads a PDF from the React UI.
2. **Extract.** The FastAPI backend extracts page text with PyMuPDF.
3. **Chunk.** Text is split into token-aware chunks (512 tokens, 50-token overlap).
4. **Embed and index.** Chunks are embedded in batches with OpenAI embeddings and stored in a FAISS index with JSON metadata.
5. **Retrieve.** Hybrid FAISS vector search with reranking selects the most relevant chunks for each question.
6. **Answer.** The retrieved context is sent to the chat model with strict grounding instructions, and the answer comes back with source citations (`S# | page N`), as a regular or streaming (SSE) response.

The app also supports multi-turn chat.

## Stack

- **Backend:** Python, FastAPI, OpenAI SDK, FAISS, PyMuPDF, tiktoken, pytest
- **Frontend:** React, Vite, Tailwind CSS
