## Overview

A POSIX-compliant, Unix-style file system built in C++.

## Design

The simulator combines three classic file-system techniques:

- **Inode data structures** — the Unix way of representing files.
- **Multi-threaded read/write locks** — readers share access while writers get exclusive access, so operations from multiple threads can run at the same time.
- **Journaling** — the technique file systems use to stay consistent after a crash.

## Results

- **70% higher throughput** than a single-threaded baseline
